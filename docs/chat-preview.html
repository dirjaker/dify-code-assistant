                    def quicksort(arr):
    if len(arr) <= 1:
        return arr
    pivot = arr[len(arr) // 2]
    left = [x for x in arr if x < pivot]
    middle = [x for x in arr if x == pivot]
    right = [x for x in arr if x > pivot]
    return quicksort(left) + middle + quicksort(right)

能解释一下 pivot 的选择吗？

这里选择数组中间的元素作为 pivot。这是一种简单且在大多数情况下表现良好的策略：

1. 避免最坏情况：如果总是选第一个元素，对已排序数组会退化为 O(n²)
2. 实现简单：arr[len(arr) // 2] 直接取中间位置
3. 平均表现好：对随机数据，中间元素通常接近中位数
