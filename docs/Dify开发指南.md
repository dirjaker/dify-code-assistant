# Dify 配置指南

本指南将帮助您配置 Dify 以最佳方式配合 `dify-code-assistant` 插件工作。

## 1. 创建应用 (Create App)

插件主要通过 **Chatflow** 或 **Agent** 模式工作。

1.  登录 Dify 控制台 (默认: http://192.168.31.100:9000)
2.  点击 "创建应用" -> 选择 **"聊天助手" (Chat)** 或 **"Agent"**
3.  推荐使用 **Agent** 模式，因为它可以自动调用工具（如代码解释器）并更好地处理上下文。

## 2. 配置输入变量 (Inputs)

插件会通过 API 发送 `inputs` 对象。为了与插件无缝配合，请在 Dify 应用的 "功能" -> "变量" 中配置以下变量（或直接使用默认上下文）：

*   **默认输入**: 插件会自动将当前打开的代码文件内容作为 `system_prompt` 或 `query` 的一部分发送。
*   **推荐设置**: 无需手动添加复杂变量，保持默认的 `query` 输入即可。插件会自动处理上下文拼接。

## 3. 编写提示词 (Prompt)

在 "提示词" 编辑区，建议使用以下 System Prompt 模板，以充分利用插件发送的上下文：

```text
你是一个专业的 AI 编程助手。请根据用户提供的【代码上下文】和【问题】进行回答。

回答要求：
1. 如果用户询问代码解释，请使用中文详细解释。
2. 如果用户要求修改代码，请直接输出完整的代码块（Markdown 格式）。
3. 保持回答简洁、专业。
4. 如果需要运行代码，请使用代码解释器工具。
```

## 4. 获取 API 凭证

1.  在应用页面左侧菜单，点击 **"访问 API"**。
2.  复制 **API Base URL** (例如 `http://192.168.31.100:9000/v1`)。
3.  创建并复制 **API Secret Key** (以 `app-` 开头)。

## 5. 插件端配置

在 VS Code 中按 `Ctrl+Shift+P` 输入 `Dify: Open Settings`，填入：

*   **API URL**: `http://192.168.31.100:9000` (注意：不需要加 `/v1`，插件会自动补充)
*   **API Key**: `app-xxxxxxxxxxxx`
*   **Model**: 可留空，或填 Dify 中配置的模型名称。

## 6. 高级：使用工具 (Tools)

在 Dify Agent 模式下，您可以开启以下工具增强插件能力：

*   **Web Search**: 让 AI 能够联网搜索最新的技术文档（如查找最新的 API 变更）。
*   **Code Interpreter**: 让 AI 能够运行 Python 代码来验证算法逻辑。

## 7. 常见问题

**Q: 为什么插件返回 "Connection Refused"?**
A: 确保 Dify Docker 服务正在运行，并且端口映射正确 (9000)。

**Q: 如何让 AI 记住整个项目的代码？**
A: 目前插件主要发送当前文件的上下文。若需项目级理解，建议在 Dify 中创建 **"知识库" (Dataset)**，上传项目的核心文档或代码索引，并在应用中关联该知识库。
